# GuaMaps Tenerife

App web de guaguas de Tenerife: salidas por parada, planificador de rutas con transbordos, todas las líneas y paradas de TITSA, planes turísticos y 5 idiomas (español, inglés, alemán, francés e italiano).

Datos de horarios: TITSA, datos abiertos GTFS (CC BY). Válidos del 17 nov 2026 al 16 may 2027.

Web: https://daniildiat-pixel.github.io/guamaps/
